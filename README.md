## Самостоятельная настройка
1. Арендуйте VPS (или используйте существующий).
2. Установите Xray-core / sing-box.
3. Сгенерируйте конфиг: `xray uuid`, `xray x25519`.
4. Проверьте через `curl -v https://www.google.com`.
